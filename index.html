How to Use the BRACU CGPA Calculator?

1

Enter Your Current CGPA: Input your current CGPA from BRAC University. This BRACU CG calculator supports the standard 4.0 grading scale used by BRACU.

2

Add Course Credits: You can edit the credits for each course. If your thesis or project is worth 4 credits, simply change the credit field to 4. This BRACU calculator handles variable credit courses.

3

BRACU Grading System: The CGPA gets rounded up if the third decimal digit is 5 or more. For example, 3.895 becomes 3.90 according to BRAC University's grading system.

4

Contribute to BRACU Community: Help improve this BRACU CGPA calculator! Visit our GitHub repository to contribute and suggest improvements.
